# Papers 06 — Agents & Tool Use

The capstone presentation of the Key LLM Publications series indexes five publications that trace the arc from a clever prompting pattern to a production-grade, vendor-neutral standard for agentic systems. It covers **ReAct** (Yao et al., 2022 — interleaving reasoning traces with tool actions and observations in the loop that underpins virtually every modern agent), **Toolformer** (Schick et al., 2023 — a model that self-supervises tool use by keeping only the API calls that measurably reduce next-token loss), **Reflexion** (Shinn et al., 2023 — "verbal reinforcement learning" that stores natural-language self-reflections in episodic memory to improve across retries without weight updates), **Building Effective Agents** (Anthropic engineering blog, 2024 — distinguishing deterministic workflows from autonomous agents and cataloguing the composable patterns of prompt chaining, routing, parallelisation, orchestrator–workers and evaluator–optimiser), and the **Model Context Protocol** (Anthropic, 2024 — an open "USB-C for AI" JSON-RPC standard that connects LLM apps to external tools, resources and prompts independent of any single model or vendor). Two of these are industry articles rather than arXiv papers, by design — the series covers papers, articles and blogs. Each slide gives the problem, the contribution, why it matters to a practising LLM/agent engineer, an original inline diagram, and a key takeaway, and the final slide synthesises the whole thirty-publication, six-deck series.
